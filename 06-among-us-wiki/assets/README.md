# Assets Folder

Coloca aquí tus imágenes de Among Us!

## Instrucciones para reemplazar las imágenes de placeholder:

1. Guarda tus imágenes en esta carpeta
2. Ve a `main.js` y actualiza las URLs en `siteData.roles` y `siteData.maps`
3. Ejemplo:
   ```javascript
   image: './assets/impostor.png' // Ruta relativa correcta
   ```

## Sugerencias de imágenes:
- **Roles**: PNGs de los crewmates/impostores con fondo transparente
- **Mapas**: Capturas de pantalla de los mapas del juego
